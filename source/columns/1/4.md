# 并发原语与内存模型

这是专栏《Rust 高级编程与异构系统》的第 4 篇文章。

## 学习目标

- 理解 Rust 内存模型的 happens-before 关系。
- 掌握原子操作与内存序的使用。

## 原子类型与 Ordering

Rust 通过 `std::sync::atomic` 提供了一系列原子类型，如 `AtomicBool`、`AtomicUsize`、`AtomicPtr` 等。每个原子操作都需要指定一个 `Ordering`，它决定了操作的可见性保证：

```rust
use std::sync::atomic::{AtomicUsize, Ordering};

static COUNTER: AtomicUsize = AtomicUsize::new(0);

fn increment() {
    COUNTER.fetch_add(1, Ordering::SeqCst);
}
```

## 五种内存序

Rust 支持五种内存序，从弱到强：
- **Relaxed**：仅保证原子性，无顺序约束
- **Release/Acquire**：用于一对一的同步
- **AcqRel**：Acquire + Release 的组合
- **SeqCst**：全局一致的顺序

```rust
// Release-Acquire 示例
static DATA: AtomicUsize = AtomicUsize::new(0);
static READY: AtomicBool = AtomicBool::new(false);

// 线程 A
DATA.store(42, Ordering::Release);
READY.store(true, Ordering::Release);

// 线程 B
if READY.load(Ordering::Acquire) {
    assert_eq!(DATA.load(Ordering::Acquire), 42);
}
```

## 内存屏障

除了原子操作，Rust 还提供了 `std::sync::atomic::fence` 函数，用于插入独立的内存屏障。屏障可以与原子操作组合，实现更灵活的内存序控制：

```rust
use std::sync::atomic::{fence, Ordering};

// 全屏障
fence(Ordering::SeqCst);
```

## 无锁数据结构

原子操作是无锁编程的基础。一个简单的无锁计数器示例：

```rust
use std::sync::atomic::{AtomicI64, Ordering};

struct AtomicCounter {
    value: AtomicI64,
}

impl AtomicCounter {
    fn increment(&self) -> i64 {
        self.value.fetch_add(1, Ordering::AcqRel)
    }

    fn get(&self) -> i64 {
        self.value.load(Ordering::Acquire)
    }
}
```

## 跨平台注意事项

内存序的行为在不同 CPU 架构上可能存在差异。x86 架构提供较强的内存模型，而 ARM 和 RISC-V 则更弱。编写可移植的并发代码时，应使用 Rust 的内存序抽象而非平台特定指令。
