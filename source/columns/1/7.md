# Rust 与 WebAssembly 异构开发

这是专栏《Rust 高级编程与异构系统》的第 7 篇文章。

## 学习目标

- 理解 wasm-bindgen 的 ABI 映射机制。
- 掌握 Rust 到 JavaScript 的跨语言调用模式。

## wasm-pack 工具链

`wasm-pack` 是 Rust WebAssembly 开发的官方工具，负责编译、打包和发布 wasm 模块：

```bash
wasm-pack build --target web
wasm-pack build --target bundler  # 用于 webpack/rollup
wasm-pack build --target nodejs   # 用于 Node.js
```

不同 target 生成不同的 JavaScript 胶水代码。

## wasm-bindgen 的核心功能

`wasm-bindgen` 通过属性宏在 Rust 和 JS 之间建立双向绑定：

```rust
use wasm_bindgen::prelude::*;

#[wasm_bindgen]
pub fn greet(name: &str) -> String {
    format!("Hello, {}!", name)
}

#[wasm_bindgen]
extern "C" {
    fn alert(s: &str);
    #[wasm_bindgen(js_namespace = console)]
    fn log(s: &str);
}
```

编译后可以直接在 JavaScript 中调用这些函数。

## 类型映射规则

wasm-bindgen 在 Rust 和 JS 类型之间自动转换：
- 基本类型（i32、f64、bool）直接映射
- `String` ↔ JS `String`
- `Vec<u8>` ↔ JS `Uint8Array`
- Rust 结构体 ↔ JS 对象（通过 `#[wasm_bindgen]`）
