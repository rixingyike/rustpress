# 宏与元编程深探

这是专栏《Rust 高级编程与异构系统》的第 5 篇文章。

## 学习目标

- 理解声明宏（macro_rules!）与过程宏的区别。
- 掌握 syn 和 quote 库编写自定义 derive 宏。

## 声明宏 macro_rules!

`macro_rules!` 是 Rust 中最基础的元编程工具，通过模式匹配对代码进行替换：

```rust
macro_rules! vec_of_three {
    ($x:expr) => {
        vec![$x, $x, $x]
    };
}

let v = vec_of_three!(42);
assert_eq!(v, vec![42, 42, 42]);
```

声明宏适合代码模板生成，但在复杂 AST 操作上能力有限。

## 过程宏的分类

Rust 的过程宏分为三类：
- **自定义 derive 宏**：`#[derive(MyMacro)]`
- **属性宏**：`#[my_attribute]`
- **函数宏**：`my_macro!()`

三者都需要在 proc-macro crate 中定义，操作 TokenStream。

## 使用 syn 解析 AST

`syn` 是 Rust 生态中最流行的过程宏解析库。它将 TokenStream 解析为结构化的 AST 节点：

```rust
use syn::{parse_macro_input, DeriveInput};

#[proc_macro_derive(MyMacro)]
pub fn my_derive(input: TokenStream) -> TokenStream {
    let input = parse_macro_input!(input as DeriveInput);
    let name = &input.ident;
    // 生成代码...
}
```

## 使用 quote 生成代码

`quote` 库提供了模板风格的代码生成方式，`quote!` 宏内部可以使用 `#var` 插值：

```rust
use quote::quote;

let name = &input.ident;
let expanded = quote! {
    impl MyTrait for #name {
        fn hello(&self) {
            println!("Hello from {}", stringify!(#name));
        }
    }
};
TokenStream::from(expanded)
```

## 完整的 derive 宏示例

下面是一个完整的示例，自动为结构体实现 `Hello` trait：

```rust
#[proc_macro_derive(Hello)]
pub fn hello_derive(input: TokenStream) -> TokenStream {
    let input = parse_macro_input!(input as DeriveInput);
    let name = &input.ident;
    let gen = quote! {
        impl Hello for #name {
            fn greet(&self) -> String {
                format!("Hello, I am {}", stringify!(#name))
            }
        }
    };
    gen.into()
}
```

过程宏在编译期执行，运行在编译器进程中，可以访问完整的 Rust 语法树信息。
