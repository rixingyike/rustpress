# 生产环境性能调优与 Fuzzing

这是专栏《Rust 高级编程与异构系统》的第 8 篇文章。

## 学习目标

- 了解 cargo-fuzz 进行模糊测试的方法。
- 掌握 perf 和 flamegraph 进行 CPU 热点分析。

## cargo-fuzz 入门

`cargo-fuzz` 是 Rust 官方的模糊测试工具，基于 libFuzzer：

```bash
cargo install cargo-fuzz
cargo fuzz init
cargo fuzz add my_fuzz_target
```

fuzz target 接收一个字节切片作为输入：

```rust
#![no_main]
use libfuzzer_sys::fuzz_target;

fuzz_target!(|data: &[u8]| {
    if let Ok(s) = std::str::from_utf8(data) {
        let _ = my_parser::parse(s);
    }
});
```

## 运行模糊测试

启动 fuzzer 并观察其发现的问题：

```bash
cargo fuzz run my_fuzz_target -- -max_len=4096 -runs=1000000
```

Fuzzer 会自动变异输入、测量覆盖率，并在触发 panic 时保存崩溃用例到 `artifacts/` 目录。

## 使用 perf 进行性能分析

Linux 上的 `perf` 工具可以采样 CPU 热点：

```bash
perf record --call-graph dwarf ./target/release/my_app
perf report
```

生成的报告会按消耗 CPU 时间的函数排序，帮助定位性能瓶颈。
