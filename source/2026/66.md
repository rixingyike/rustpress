# AI 时代，站在针尖上的人越来越珍贵

去年做过的一个小浏览器插件功能，今天重新拾起来，我硬是拖了一天一夜才动手。

不是不会写，是心静不下来了。

去年做这个功能的时候，我基本上是半手写半 AI 协助，那时候心境主要还在编码上，能耐下心一点一点扣代码。今天不同了，这一年我大部分时间在搞文学创作，心境整个变了。

我自己琢磨，写代码是稳、是心静如水；搞创作是快，是天马行空。天马行空惯了，想静下心来一点一点扣代码，很难不到。

于是这项「不是新功能的功能」，被我拖了一天一夜。

今天我终于忍不住主动查了资料，想看看在 **agy** 指挥浏览器操作网页 ==DOM== 这件事上，有什么趁手的工具或类库。不查不知道，一查还真有。耐心看了资料、简单学习一下上手之后，小小的新功能在一小时内搞定了，而且只用了 `DS 4.0 Flash Free` 模型，不花钱就办成了事。

怎么做到的呢？也算一个小经验，我简述一下。

## 一）Browser MCP Extension

第一种方法，在浏览器上装 [Browser MCP Extension](https://browsermcp.io/install)，再在 agy 的全局 mcp_config 文件里加上 browsermcp：

```json
{
  "mcpServers": {
    "browsermcp": {
      "command": "npx",
      "args": ["@browsermcp/mcp@latest"]
    }
  }
}

```

装好以后，mcp 服务由 agy 自动管理。要停的话，用 `/mcp` 指令手动 disable。

使用也不复杂。在浏览器插件上点一下 Connect 按钮，本地的 `MCP Server` 已经启动，会自动连上。然后在 agy 中就能用指令直接访问和操纵页面 DOM 了。插件是按 Tab 分的，在哪个 Tab 上 Connect，就操纵哪个 Tab。

原理也简单，基于谷歌的 `Model Context Protocol (MCP)` 协议，在本地 CLI 工具和浏览器之间搭了一条通道。本地工具本来访问不了网页 DOM，搞个插件做中介，把信息搬过来、把指令传过去。

但这种方式有个不完美的地方：不能截图保存到本地。

## 二）Playwright

第二种工具，是大名鼎鼎的 **Playwright**。先全局安装：

```bash
npm install -g @playwright/cli@latest

```

再在 CLI 里安装它的 SKILL：

```bash
microsoft/playwright-cli/skills/playwright-cli

```

可以用 skills 或 degit 安装。可能还有一些依赖项没写全，不用担心，用 AI CLI 安装和启动，它会自动补齐。

装好以后怎么用？举一个官方示例：

> 使用 playwright-cli 连接到 `http://localhost:5173` Web 应用程序。然后，使用用户名 `admin` 和密码 `password` 进行登录，并验证仪表盘的标题是否显示为 `System Overview`。对仪表盘进行截图，并将其保存至 `docs/dashboard.png`。最后，在主仪表盘中读取显示的遥测数值，并将这些数据以 Markdown 表格的形式反馈给我。

这样一条简单的提示语就够了，agy 知道怎么找控件、填表单。

原理是什么呢？

Playwright 安装的时候会自动下一个特殊版本的 chromium 内核浏览器，这个浏览器里包含了「插件」，Playwright 在本地能直接连上。软件都是特殊版本，截图就没有问题。

如果要写浏览器插件代码怎么用它？也很简单，举个提示语示例：

> 用 playwright-cli 这个工具，打开「xxx」网页，尝试执行 scripts/xxx 这个脚本。脚本可能有错误，不要紧，总体顺序是：先找到章节名称，输入随机标题；再找到正文，输入 2000 字随机正文；然后点「立即发布」，打开发布面板；点「确认」发布，完成内容的立即发布。你要记录点了什么控件、随机输入了什么，把过程写成 IIFE js 函数，放在 scripts 目录下，方便我可以在 console 面板里独立执行。

这样就可以了。给它一点时间，agy 或 opencode 就自动把 js 脚本写好了。

要是搁在古法时代，做类似的功能要手动查 DOM、写 js 验证，因为网页大多是用 Vue 或 React 这种响应式框架写的，DOM 控件并不是很好操作，得花很长时间。现在有了这些工具，变得容易多了。

## 三）ego-browser

第三招，装 ego-browser。ego 是一个浏览器，官方原话是「同时给人类和 AI Agent 用」。你只要装上它，把上一条提示语里的 playwright-cli 换成 ego-browser，什么也不用配置、什么也不用改，ego 自动把所有事帮你做完。

它怎么做到的？其实也简单，无非就是 ego 里面既塞了一个插件，又塞了一个类似 Playwright 的本地服务。它帮我们集成好了，拿来就能用。

如果世界上没有人走到前面，倒也没什么；怕的是有人走在前面了，只是我们被信息蒙蔽了不知道，那我们就真跟傻子一样了。

在 AI 时代，什么人最珍贵？仍然是站在针尖上的人。他们在某个具体的垂直细分领域走在了最前面，并且还在一直往前走；他们使用最先进的工具，用最正确的思想武装自己，永远占据着针尖上的位置。
